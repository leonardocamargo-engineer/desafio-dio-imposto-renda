# Desafio DIO - Organizador de Imposto de Renda

## Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de criar uma ferramenta em Excel para auxiliar na organização das informações necessárias para a declaração do Imposto de Renda.

A planilha permite centralizar dados pessoais, informes bancários e comprovantes de rendimentos, facilitando o preenchimento e o controle das informações.

## Funcionalidades

- Cadastro dos dados do titular
- Registro de informes bancários
- Controle de rendimentos
- Validação de dados
- Navegação entre abas
- Interface organizada e intuitiva

## Ferramentas Utilizadas
